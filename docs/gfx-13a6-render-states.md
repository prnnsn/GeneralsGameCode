# GFX 13a.6b/c — typed depth, blend, alpha and stencil states

Adds typed neutral states with explicit DX8 conversion. ShaderClass keeps legacy source blend LUT (including DESTCOLOR for its fourth entry), depth comparison order, alpha reference and call sequence. The shared shader cached calls still use DX8Wrapper's cache. The two shadow variants use explicit immediate writes for existing raw-device calls; do not collapse those into cached calls or remove existing invalidation. Color write-mask get/restore, shader legacy global cull and other states remain native; this is a focused slice, not full completion of Phase A. Review shader enum order, raw call trace, shadow stencil/alpha/cull behavior, state invalidation and both build variants. No engine build or runtime test performed.
